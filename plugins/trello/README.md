# TaskWeight Trello Power-Up

AI-плагин для автоматической оценки сложности и времени выполнения задач в Trello с использованием OpenAI GPT.

## 🚀 Возможности

- **AI-оценка задач**: Автоматическая оценка времени выполнения с использованием OpenAI GPT
- **Интеграция с GitHub**: Анализ репозиториев для более точной оценки
- **Умные бейджи**: Отображение прогноза времени прямо на карточках
- **Настройки Power-Up**: Гибкая конфигурация параметров оценки
- **Обратная связь**: Сохранение результатов оценки в Trello

## 📁 Структура файлов

```
plugins/trello/
├── manifest.json          # Конфигурация Power-Up для Trello
├── connector.html         # Основной файл интеграции с Trello
├── index.html            # Интерфейс оценки задач
├── settings.html         # Страница настроек Power-Up
├── script.js             # JavaScript логика
├── style.css             # Стили интерфейса
└── README.md             # Документация
```

## 🛠️ Установка

### 1. Подготовка сервера

Убедитесь, что ваш TaskWeight сервер запущен и доступен по адресу `http://localhost:8000` (или другому URL).

### 2. Размещение файлов

Разместите все файлы плагина на веб-сервере, доступном из интернета. Рекомендуется использовать:
- GitHub Pages
- Netlify
- Vercel
- Собственный веб-сервер

### 3. Создание Power-Up в Trello

1. Перейдите в [Trello Power-Ups Admin](https://trello.com/power-ups/admin)
2. Нажмите "Create a Power-Up"
3. Заполните форму:
   - **Name**: TaskWeight
   - **Details**: AI-powered task estimation system
   - **Icon**: Загрузите иконку (16x16px)
   - **Capabilities**: Выберите все необходимые возможности
   - **Connectors**: Укажите URL к `connector.html`

### 4. Настройка доменов

В настройках Power-Up добавьте ваш домен в список разрешенных источников.

## 🔧 Конфигурация

### manifest.json

Основной файл конфигурации Power-Up:

```json
{
  "name": "TaskWeight",
  "details": "AI-powered task estimation system",
  "capabilities": [
    "callback",
    "card-badges",
    "card-buttons",
    "card-detail-badges",
    "show-settings"
  ],
  "connectors": {
    "iframe": {
      "url": "./connector.html"
    }
  }
}
```

### Настройки Power-Up

В `settings.html` можно настроить:
- **API URL**: Адрес вашего TaskWeight сервера
- **Модель AI**: Выбор модели OpenAI (GPT-4, GPT-3.5 Turbo)
- **Порог уверенности**: Минимальная уверенность для принятия оценки
- **Автооценка**: Автоматическая оценка новых карточек
- **Уведомления**: Включение/выключение уведомлений

## 📱 Использование

### 1. Активация Power-Up

1. Откройте доску Trello
2. Нажмите "Show Menu" → "Power-Ups"
3. Найдите "TaskWeight" и нажмите "Add"

### 2. Оценка задачи

1. Откройте карточку задачи
2. Нажмите кнопку "🎯 Оценить задачу"
3. Заполните форму:
   - Укажите GitHub репозиторий
   - Опишите задачу
   - Выберите приоритет и сложность
4. Нажмите "Оценить задачу"
5. Дождитесь результата от AI

### 3. Просмотр результатов

- **На карточке**: Отображается бейдж с прогнозом времени
- **В деталях карточки**: Полная информация об оценке
- **В Power-Up**: Детальный анализ и возможность сохранения

## 🔌 API интеграция

### Endpoints

- `POST /api/v1/estimate` - Запуск оценки задачи
- `GET /api/v1/estimate/{card_id}` - Получение статуса оценки
- `POST /api/v1/webhooks/trello` - Webhook для уведомлений

### Формат запроса

```json
{
  "cardId": "trello_card_id",
  "taskDescription": "Описание задачи",
  "repoUrl": "https://github.com/user/repo",
  "priority": "medium",
  "complexity": "medium"
}
```

### Формат ответа

```json
{
  "id": "estimation_id",
  "cardId": "trello_card_id",
  "status": "estimated",
  "estimatedHours": 8.5,
  "createdAt": "2025-01-10T12:00:00Z"
}
```

## 🚨 Устранение неполадок

### Частые проблемы

1. **Power-Up не загружается**
   - Проверьте доступность файлов
   - Убедитесь в корректности URL в настройках

2. **Ошибки API**
   - Проверьте доступность сервера
   - Убедитесь в корректности API URL в настройках

3. **Бейджи не обновляются**
   - Проверьте права доступа Power-Up
   - Убедитесь в корректности callback функций

### Логи

Включите отладку в браузере для просмотра ошибок JavaScript и сетевых запросов.
