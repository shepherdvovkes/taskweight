📊 Доступные Endpoints

  • GET /health - Проверка состояния сервера
  • POST /api/v1/estimate - Запуск оценки задачи
  • GET /api/v1/estimate/{card_id} - Получение статуса оценки
  • POST /api/v1/trello/card/{card_id}/estimate - Trello оценка
  • GET /api/v1/trello/card/{card_id}/stats - Статистика карточки
  • POST /api/v1/trello/card/{card_id}/metadata - Обновление метаданных
